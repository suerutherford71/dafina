Starting the catalogue

  1. Double-click Start Catalogue.command in your Dafina folder. It opens http://localhost:4610 in your browser.
  2. Keep that small Terminal window open while you use the catalogue. Closing it stops the catalogue.
  3. The green Live dot (top right) means the catalogue is watching your folders. If it turns red, the catalogue has stopped. Double-click the start file again.

Adding inspiration

Use whichever way is easiest:

  • + Add button. Pick a category and an optional sub-folder, then drop in images. Choose + New category… to start a new one, or type a new sub-folder name to create it. You can add a source link (applied to every image in that batch) and a note for Claude, such as what you like about it.
  • Bulk upload. Drop as many images as you like, or whole folders. With “keep their names as sub-folders” ticked, a dropped folder becomes a sub-folder.
  • Paste. Take a screenshot to the clipboard (⌘⇧⌃4), then press ⌘V anywhere on the page.
  • Drag and drop images straight onto the page.
  • Finder. Put images straight into any folder inside sources/. They appear here within a few seconds.
  • Website links. In + Add → Websites, paste as many links as you like, one per line. Dafina opens each page in Chrome in the background, takes a fresh screenshot, and saves it with the link, the page title and its description. Tick “longer section” to capture about three screens instead of just the top. Refero style links work here too.
  • Chrome extension. Click Save to Dafina in Chrome's toolbar to save the page you're looking at, with its link. You can pick the category, sub-folder and a note. Right-click any image on a page and choose Save image to Dafina to save just that image.
  • Figma plugin. Select one or more frames in Figma, run Save to Dafina (Plugins → Development), pick a category and click Save to Dafina. Each frame is saved as a PNG (1×, 2× or 3×) with a note saying which file and page it came from, plus a link back to the frame when Figma provides one.

Installing the Chrome extension (once): in Chrome, go to chrome://extensions, turn on Developer mode (top right), click Load unpacked and choose the chrome-extension folder inside your Dafina folder. Then click the jigsaw icon in Chrome's toolbar and pin Save to Dafina. Dafina must be running for it to save.

Installing the Figma plugin (once): open the Figma desktop app (the plugin can't reach Dafina from Figma in a web browser). Go to Plugins → Development → Import plugin from manifest… and choose manifest.json in the figma-plugin folder inside Dafina. It then appears under Plugins → Development → Save to Dafina.

New images show an Awaiting labels badge until Claude has described them.

Getting Claude to add labels

  1. Open Claude Code (the Code tab in the Claude desktop app) with the Dafina folder selected.
  2. Type: label my dafina
  3. Claude looks at every image that has no labels yet and adds a title, style line, labels, colour palette, typography, layout, mood, design brief and an image recipe. The page updates by itself.

Shortcut: on the Awaiting labels page (or inside any item still waiting), click Label with Claude. It copies label my dafina and opens the Claude app, so you only need to start a Code session in your Dafina folder and paste.

Useful variations:

  • Just one area: “catalogue the new cards” or “catalogue everything in clipart”
  • Changes: “make the Sweet Winter recipe more vintage”
  • Redo: “re-label the journals with more detail on the embellishments”
  • One exact item: click Copy reference (or the copy icon on its card) and paste it in with your request.

The Awaiting labels pill shows how many images still need doing. Notes and links you add when uploading help Claude write better labels.

Categories and sub-folders

  • Your folder Dafina/sources/ runs the catalogue. Each folder inside it is a category, and each folder inside that is a sub-category, at any depth (for example cards › lucy › birthday).
  • Add, rename, move or delete folders and images in Finder whenever you like. The catalogue updates within a few seconds.
  • Rename in the app: open a category (or one of its sub-folders) and click ✎ Rename at the end of the folder row. It renames the real folder on your Mac, and every image keeps its labels, link and notes. To rename a category, open the category itself; to rename a sub-folder, open that sub-folder first.
  • Labels stay attached to the image itself, so moving or renaming a file keeps its labels and link.
  • A new top-level folder in sources/ becomes a new category automatically.
  • Folder names can be lowercase. The site just shows them capitalised.

Importing website styles from Refero

What is Refero? Refero is a website of design inspiration for UI and web designers. Its Styles library (styles.refero.design) takes the look of well-known product websites and breaks each one down into its colours, fonts, spacing and components. Each style comes with a DESIGN.md: a plain-text style guide that AI tools such as Claude can follow. You don't need Refero to use this catalogue; it's just a quick way to collect website styles with exact details.

  1. Browse styles.refero.design and open a style you like. Copy its link (it looks like styles.refero.design/style/…).
  2. Click + Add → Import from Refero and paste one or more links, one per line.
  3. Each import saves the screenshot, the link, Refero's description and the full DESIGN.md (exact colours, fonts and spacing). These go into web design › refero unless you choose another folder.
  4. Ask Claude to label my dafina. It uses the DESIGN.md for accurate colours and fonts.

Finding things

  • Category pills filter by category. Once one is open, its folders appear underneath. Click one to go deeper, and use the breadcrumb to go back up.
  • Drag a category pill left or right to put the categories in your own order. It's saved straight away. New categories join at the end. To go back to the original order, ask Claude to “reset my category order”.
  • Search looks through titles, labels, colours (names and hex codes), notes, folders and file names.
  • Click any label to see everything with that label. Click more labels to narrow down further.
  • ★ shows favourites only. Use Newest / Oldest / A–Z to change the order.
  • Dark mode: the moon button (top right) switches to dark mode, and the sun switches back. The catalogue remembers your choice. Until you pick one, it follows your Mac's appearance setting.

Using an item

Click a card to open it.

  • Visit source ↗ opens where you found it (also the ↗ button on the card).
  • Copy brief copies a full design description to paste into Claude or a design tool.
  • Copy image prompt copies the recipe. Replace the highlighted [SUBJECT: …] with your own subject, then paste it into your image generator.
  • Copy reference (or the copy icon on the card) copies a short line that points to exactly this item. Paste it to Claude with what you'd like done, for example “make this recipe more watercolour: “Sleeping Fox” — Clipart › Christmas Woodland Animals PNGs › PNG-06.png · id …”.
  • Click a colour swatch to copy its hex code.
  • DESIGN.md (Refero items) shows or copies the full style guide.
  • Click the big image to see it full length. Use ← → to move between items.

Editing, moving and deleting

  • Edit (or Edit / add link on new items) lets you add a source link, change any label, or rewrite the brief and recipe.
  • Changing Category or Sub-folder in Edit moves the actual file. Choose + New category… or type a new sub-folder name to create one.
  • Delete moves the image to the trash folder inside Dafina, so you can get it back from there.
  • Several at once: tick the checkbox at the top left of a card. As soon as one is ticked, a bar appears at the bottom, and clicking anywhere on another card selects it too. Shift-click selects everything between two cards, and Select all picks everything currently shown. Use the bar to:
    • Copy references: copies one reference line per selected item. Paste them to Claude with what you'd like done, for example “write one image prompt that blends these styles”.
    • Edit…: move them all to another category or sub-folder, add labels, remove labels, set one source link or add a note.
    • ★ Favourite or unfavourite them.
    • Delete them (they go to the trash folder).
    Click Clear or press Esc to untick everything.

If something isn't working

  • “The catalogue server isn't running” or a red Live dot: double-click Start Catalogue.command.
  • The page looks out of date after an update: double-click the start file again. It replaces an older running copy. Then reload the page.
  • macOS blocks the start file the first time: right-click it, choose Open, then Open again.
  • A new image doesn't appear: check it's inside sources/ and is an image (PNG, JPG, WEBP, GIF, SVG, HEIC, TIFF). OneDrive files that are “online only” may take a moment to download.
  • Anything else: ask Claude in the Dafina folder, e.g. “the catalogue isn't showing my new folder”.
