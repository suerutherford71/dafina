How it works

Save it. Claude labels it. Find it.

No tagging, no boards to curate, no account to create. Three steps, and the boring part isn't yours.

1

Drop it in

Paste a screenshot, drag in a whole folder, save a page from Chrome or a frame from Figma, or paste a list of links and Dafina screenshots each website for you.

2

Ask Claude to label it

Open Claude and type label my dafina. Claude looks at every new image properly and writes its title, labels, colours, brief and image prompt.

3

Find it in seconds

Search serif headline, sage green or #1F6F8B. Click any label to see everything like it. Copy a brief or palette in one click.

What Claude writes

Every image, described like a designer would.

Not just "website, green". Real, searchable detail, plus a ready-made prompt to make something new in the same style.

Install

Up and running in about two minutes.

One line installs Dafina and opens it. No account, no sign-up, nothing to pay.

1

Open Terminal

Press ⌘ Space, type Terminal and press Return.

2

Paste this line and press Return

curl -fsSL https://raw.githubusercontent.com/suerutherford71/dafina/main/install.sh | bash

If your Mac asks to install "command line developer tools", click Install, wait for it to finish, then paste the line again.

3

Dafina opens in your browser

Your library lives in a Dafina folder in your home folder. Next time, just double-click Start Catalogue inside it.

4

Add images, then ask Claude

In the Claude desktop app, open the Code tab, choose your Dafina folder and type label my dafina.

Why Terminal and not a download? macOS shows a security warning for apps downloaded from websites unless the maker pays Apple to approve them. Installing with one line avoids that warning, and you can read exactly what it does first. Running the same line again updates Dafina and never touches your library.

Questions

Good to know.

Is Dafina really free?

Yes, completely. If it saves you time, you're welcome to buy me a coffee, but there's no catch and nothing to unlock.

Are my images uploaded anywhere?

Dafina itself never uploads your images. They stay in your own folder on your own Mac. When you ask Claude to label them, Claude looks at the new images through your own Claude account, just as it would any file you share with it. You can keep the folder in OneDrive, Dropbox or iCloud Drive for backup.

Why do I need a paid Claude plan?

The labelling is done by Claude, using the Code tab in the Claude desktop app, which comes with paid plans. Everything else (saving, browsing, searching, copying) works without it.

How do I add the Chrome extension?

Click "Add to Chrome" above. If the Chrome Web Store link isn't live yet: go to chrome://extensions, turn on Developer mode (top right), click Load unpacked and choose the chrome-extension folder inside your Dafina folder. Then pin Save to Dafina from the jigsaw icon.

Does it work on Windows?

Not yet. Dafina is Mac only for now.

How do I update or uninstall it?

To update, paste the install line into Terminal again: your images and labels are kept. To uninstall, close the Terminal window that's running Dafina and drag the Dafina folder to the Bin (move your images out first if you want to keep them).

Is Dafina made by Anthropic?

No. Dafina is an independent project that works with Claude. It isn't made, endorsed or supported by Anthropic.
